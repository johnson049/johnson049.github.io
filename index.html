Projects

Cross-Technology Interface for IoT Connectivity Stack

A Unified Configuration Abstraction Layer (UCAL) that lets a host configure Wi-Fi and BLE devices through one interface, using a separate adapter for each technology. It includes firmware for profile generation, parameter management and packet encoding, with Protocol Buffers keeping messages compact and structured. I tested it in simulation and on hardware, measuring packet delivery ratio, round-trip time and reliability.

  • Python
  • Wi-Fi

  • Protocol Buffers

Wireless 3-Axis Camera Gimbal

Two ESP32 boards, one as a joystick transmitter and one as the gimbal receiver, linked over ESP-NOW so no router is needed. Averaging and dead-zone filtering on the ADC input keep the servos steady, and PWM control drives yaw, pitch and roll with either positional or continuous-rotation servos. It runs from an 18650 Li-ion cell with TP4056 charging and protection.

  • ESP32
  • ESP-NOW
  • Embedded C
  • PWM
  • PCB design

Smart Medicine Reminder and Monitoring System

An ESP32 device with RTC-based multi-alarm scheduling, snooze, weekday selection and EEPROM storage. Reed sensors detect when a pill is taken, and adherence logs go to Supabase through REST APIs so a Flutter dashboard can show medication history and device status. A local LCD, buzzer and LEDs handle reminders on the device itself.

  • DS3231 RTC
